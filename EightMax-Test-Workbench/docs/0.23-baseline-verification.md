## Unfinished, stubbed or simulated in 0.18.0
* `SolverBridge` in `src/engine.js` is a stub ("no external strategy engine connected"); the ten-table simulator used only a scripted random policy.
* No state-to-solver adapter: observations/simulator states were never converted into study roots ("state-to-study equivalence still need an adapter" — ARCHITECTURE.md).
* Vision: fixed-layout whole-region template matching on user-loaded images; no digit/number reading, no marker detection, no layout registry, no recorded-observation replay.
* No decision queue, cache keyed on live state, stale-decision protection across solver and table, no execution layer, no multi-table scheduler, no resource budgets.
* Dashboard: ten simulator cards only; no solver recommendations, no monitoring, no diagnostics export, no hardware view.
* Host launcher compiled the C# source on first launch (no prebuilt binary).
* Windows execution, visual browser testing, installer behavior and real capacity: unverified (as the 0.18.0 notes said).
* No GPU path in the bundled CLI protocol-4 CPU job flow.
