## Incomplete or missing components found
* No screen-capture module: nothing produced pixels from a window or the desktop (`vision-ocr.js` read user-loaded images only).
* Vision validated only against synthetic images from its own renderer; digit templates came from a single numeral box; no hand id, all-in, action-control, call-amount or minimum-raise reading; hero view fixed at seat 0.
* No action history from screens: `requestFromState` needed `obs.actions`, which an image never supplies; per-seat contributions, minimum raise and reopening were taken on trust from the simulator feed.
* Solver mapping: preflop push/fold only (equal 25 BB), no flop/turn/river, no multiple bet sizes, no EV.
* Executor: `bet` not distinguished from `raise`; no acknowledgement from an independent reading; no latency statistics; QA transport was only an injected function.
* Multi-table: ten cooperative workers on one thread (a synchronous solver stall freezes every table and cannot be timed out); benchmarks mixed "lookup" with "pipeline".
* GPU: not implemented (unchanged).
* Study data / checkpoints: the 0.23 checkpoint format (`eightmax-multitable-checkpoint`) and all study/workspace formats are unchanged and their tests still pass; 0.24 adds new, separate checkpoint formats.
