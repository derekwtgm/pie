## E. Solver integration
* Engine: EightMax 5.1 (build 7d08acc7eb4577ee), JS reference + native CLI; no newer engine; nothing labelled equilibrium/GTO.
* Supported: eight-handed 25 BB equal-stack linked preflop tree (SB 0.5 / BB 1 / ante 0.1), on-demand flop/turn/river studies from the reconstructed state (assumed ranges, bet menus 33/75 % flop, 50 %/all-in turn and river); EV per action when exposed; probabilities; fingerprint; study id; convergence "unproven".
* Everything else (other stacks, blinds/antes, player counts, off-tree histories) returns **structured unavailable** with a code and the missing capability; unsupported actions are never executed; fallbacks are Simulation-only and labelled.
* Coverage: 88.5 % (0.24) → 89.1 % over 90 hands (768 / 862), 89.4 % over 240 pixel-pipeline hands (2,045 / 2,288). **Not the 95 %+ one would want.** All but 3 remaining fallbacks are `no-stored-row`. A coverage test at 250,000+ preflop updates failed because the study adapter's 256 MiB strategy-memory cap is exceeded at that tree size; 100,000 updates is the practical maximum of this configuration. Translation (default off) removes off-tree unavailability but is an approximation.

## F. Automated simulation
* 1,000 complete hands from pixels with scripted decisions, variable stacks 2.1–90 BB: 1,000 complete, 0 suspended, 0 rejected frames, 0 ack mismatches, 0 duplicates, chips conserved (19,659 actions).
* 240 complete hands from pixels with EightMax decisions: 2,045 solver actions, 243 labelled fallbacks, 0 suspended; 48-hand run: 398 / 49.
* Ten tables, 1,000 hands (structured feed + lookups): 7,910 solver / 64 fallback actions, 0 crashes, 0 deadline misses, fault isolation (crash, corrupt table, garbage observation, solver stall) and emergency stop pass; checkpoint restart reproduces the final state.
* 4,000-hand rules differential: 44,607 actions, 19,483 all-in actions, 3,920 multiway showdowns, 0 mismatches. 30-hand scenarios (3 seeds): replay audit identical, chips conserved.
* Every action was acknowledged by the **next screen reading** in the pixel pipeline (`ackMismatches 0`).
